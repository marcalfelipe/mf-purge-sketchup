# Contributing

Contributions are welcome. Bug reports should include the app version, Windows
version, SketchUp file version, relevant log lines and reproducible steps. Do
not upload confidential `.skp` models to public issues.

For code changes:

1. Fork the repository and create a focused branch.
2. Keep the original input model immutable.
3. Test with copies of small models before testing large files.
4. Verify that a purged output can be reopened by the SketchUp API.
5. Update translations whenever user-facing text changes.
6. Open a pull request explaining the behavior and validation performed.

By submitting a contribution, you agree to license it under the repository's
MIT license.
