# Changelog

All notable changes to this project will be documented here.

## [1.1.0] - 2026-10-21

### Changed

- Rebuilt the real application interface to match the published preview.
- Added a pale-blue rounded header, high-resolution app artwork, white cards,
  a larger red purge button and a dedicated processing-log panel.
- Replaced the native progress bars with smooth green/blue indicators.
- Added live CPU and RAM percentage indicators in the footer.
- Expanded the window to a responsive landscape layout.

## [1.0.0] - 2026-10-21

### Added

- Standalone purge of unused SketchUp components, groups, materials and textures.
- Drag-and-drop and file-picker workflows.
- Real-time processing log, progress bar, elapsed time, CPU and memory status.
- Preservation of definitions referenced by scenes and section planes.
- Output validation by reopening the generated model through the SketchUp API.
- English, Portuguese, Spanish, German, French, Russian, Vietnamese and
  Simplified Chinese interfaces.
- Portable, self-contained Windows x64 build with no SketchUp installation
  required.
